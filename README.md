# RARA STUDIO

Responsive React + TypeScript landing page for RARA STUDIO, with four subscription tiers and a demo-only sign-in / OTP flow.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

> Authentication is a front-end simulation only. It does not connect to Google, WhatsApp, an owner approval bot, or an authentication backend, and it does not send or validate real OTPs.
